# Background transition stills

`demo-from.svg` and `demo-to.svg` are authored Jungle Nexus dawn/night illustrations, retained from the isolated production-engine verification fixture. They are local sample content, independent of the user's media library.

The 226 small JPEGs are fixed-progress (0.5) snapshots rendered by the actual selected GL Transitions and Curtains production adapters using those illustrations. The picker loads still files; it does not run an engine per card. `thumbnails.json` records the exact effect order, source illustration hashes and generated JPEG hashes/dimensions. Verification checks it against the production catalogue.

Selected engine/source distribution notices remain under `licenses/background-transitions/`. No Codrops, Motion, Anime.js or comparison-lab code is loaded by this picker.
